Fillaprint v0.1.0 is a beta typeface for small FDM-printed labels. We are fine-tuning the letterforms, spacing, and print behavior for release, with an eventual Nerd Fonts launch as a future target. This is not an official Nerd Fonts release.

Download **Fillaprint-0.1.0-beta.zip** for all three families, installation notes, and the SIL Open Font License 1.1. Internal OpenType version: **0.100**.

- **Fillaprint:** proportional letters and kerning.
- **Fillaprint Tab:** proportional letters with equal-width digits.
- **Fillaprint Mono:** fixed-width character cells.

[Try the font, calculate a print size, and view specimens](https://thereprocase.github.io/fillaprint/).

Nominal strokes and minimum clear gaps use two extrusion widths. Check your own sliced preview. The rebuild uses pinned dependencies and may differ slightly from the earlier working-name binaries. This release rebuilds and packages the existing glyph sources under the Fillaprint name; it does not claim new physical-print validation.

The family names will remain stable for compatible updates. Each release gets a new version and archive. Keep this ZIP with projects that need exact repeatability: future font changes may alter text layout or geometry. Replace installed beta fonts and restart your design application when updating.
