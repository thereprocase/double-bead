A font for multi-colour FDM text. Every stroke is exactly two extrusion widths, so the slicer prints it as one wall loop passing itself: no hairlines, no gap fill, no one-bead strokes.

Size it to your line width

The font is drawn in line widths (w). Set it from the line width your slicer uses for the outer wall and top surface. Larger is always fine; smaller puts strokes under two beads.
